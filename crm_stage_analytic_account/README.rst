This module allows you to configure, per CRM stage, whether an analytic
account should be automatically created and linked to the
lead/opportunity when it reaches that stage. The analytic account is
created using the analytic plan configured on the stage.

**Table of contents**

.. contents::
   :local:

Usage
=====

- Go to **CRM > Configuration > Stages**.
- On the desired stage (e.g. *Qualified*), check **Create Analytic
  Account** and select an **Analytic Plan**.
- Move a lead/opportunity to that stage.
- An analytic account is automatically created and linked to the
  opportunity in the **Analytic Account** field (below the phone
  number).
- If the lead already has an analytic account, no new account is
  created.
- The analytic account's ``code`` is generated from the
  ``CRM Lead Analytic Account`` sequence (**Settings > Technical >
  Sequences & Identifiers**), which can be freely reconfigured (prefix,
  padding, next number, etc.).
