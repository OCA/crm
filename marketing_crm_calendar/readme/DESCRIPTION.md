This module adds automatic marketing field propagation from CRM phonecalls to calendar events. It ensures that marketing campaign information (campaign, source, and medium) is automatically transferred when creating calendar events from phonecalls.

When a calendar event is created from a phonecall using the "Schedule A Meeting" button, the marketing fields (UTM Campaign, UTM Source, and UTM Medium) are automatically copied from the original phonecall to the new calendar event.

This functionality maintains marketing tracking consistency across different CRM activities, allowing better analysis of campaign effectiveness and lead source performance throughout the entire customer journey.

The module also creates a reference link between the phonecall and the calendar event for complete traceability.
