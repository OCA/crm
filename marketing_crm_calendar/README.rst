This module adds automatic marketing field propagation from CRM
phonecalls to calendar events. It ensures that marketing campaign
information (campaign, source, and medium) is automatically transferred
when creating calendar events from phonecalls.

When a calendar event is created from a phonecall using the "Schedule A
Meeting" button, the marketing fields (UTM Campaign, UTM Source, and UTM
Medium) are automatically copied from the original phonecall to the new
calendar event.

This functionality maintains marketing tracking consistency across
different CRM activities, allowing better analysis of campaign
effectiveness and lead source performance throughout the entire customer
journey.

The module also creates a reference link between the phonecall and the
calendar event for complete traceability.

Usage
=====

To use this module for automatic marketing field propagation:

1. Go to **CRM > Phone Calls > Create**.

2. Fill the required phonecall fields (name, date, duration, etc.).

3. In the **TRACKING** section, fill the UTM fields:

   - **Campaign**: Select the marketing campaign (e.g., "Spring Sale")
   - **Source**: Select the traffic source (e.g., "Facebook")
   - **Medium**: Select the marketing medium (e.g., "Facebook Reels")

4. **Save** the phonecall.

5. Click the **"Schedule A Meeting"** button in the top toolbar.

6. Create the calendar event with your desired details (date, time,
   attendees, etc.).

7. **Save** the calendar event.

8. The marketing fields (Campaign, Source, Medium) will be automatically
   copied from the phonecall to the calendar event.

**Note**: The automatic field copying works specifically when creating
calendar events through the "Schedule A Meeting" button from phonecall
records. Marketing fields are copied only if they exist in the original
phonecall.

**Traceability**: You can always trace back which phonecall generated a
calendar event by checking the "Phonecall" field in the calendar event
form.
