## To Configure Default Project for the Module
- Go to the General Settings > CRM > CRM
- Select a default project for tasks in the "CRM State Project Task" field

## To Cofigure Tasks for the Stage
Go to CRM > Configuration > Pipeline > Stages
- Select a record
- In the "Tasks" filed add a new record
- In the Task form view write the task template

Optional:
- Enable "Validate Task Completion" to enforce: All stage tasks must be Done/Canceled before pipeline progression
