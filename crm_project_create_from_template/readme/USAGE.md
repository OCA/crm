To create a project from a CRM lead or opportunity using a project template:

1. Create or open the project that will be used as template.
2. Enable the **Is Template?** option on that project.
3. Open a lead or opportunity.
4. Click the **Create Project** button.
5. Select the project to use as template in the **Project Template** field.
6. Fill in the project name and, optionally, the project description.
7. Click **Create Project**.

The **Project Template** field only shows projects marked as templates.

The new project is linked to the lead or opportunity. If a project template is
selected, the new project is copied from that template, including its tasks. If
no project template is selected, the standard project creation behavior from
CRM Project Create is kept.
