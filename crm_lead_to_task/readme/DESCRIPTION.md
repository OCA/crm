This module allows you to convert leads or opportunities into project tasks or link a task with one.
It supports the following features:

- Optional automatic archiving of the lead after conversion.

- Ability to convert a lead to task or create a task and link it to the lead using the wizard.

- Ability to configure a Force Project to have a preselected project on the wizard.

- Preserves attachments and messages from the lead when converting.

- When linking a new task, attachments and messages are not passed and lead/opportunities are not archived.
